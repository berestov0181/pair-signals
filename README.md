## Как работает

- Сканирует 153 пары из 19 токенов каждый час
- Находит дислокации через z-score (O1Engine v3.1)
- Сигнал при z > 2.0, закрытие при z < 0.5
- Новостной триггер: реагирует на hack/exploit события

## Как следовать сигналам

1. Открыть страницу выше
2. Найти пару из таблицы активных сигналов
3. Открыть позицию в указанном направлении (5-10% депозита)
4. Закрыть когда z-score вернётся к 0 (обычно 1-48 часов)
